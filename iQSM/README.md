# iQSM — Instant Quantitative Susceptibility Mapping

Single-step instant QSM from MRI raw phase using Laplacian-enabled deep neural networks.

**The full code, data, and documentation have moved to the standalone repository:**

## https://github.com/sunhongfu/iQSM

Please visit that repo to get started.
